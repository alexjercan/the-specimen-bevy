# Changelog

## [0.1.0] - 2026-10-09

Initial playable release of The Specimen.

- Explore a facility with a pursuing monster, doors, hiding places, and an exit objective.
- Collect three fuses to unlock the exit; use a flashlight, flashbangs, and a detector to survive.
- Experience facility lighting, power outages, spatial audio, and cinematic game screens.
- Build for Linux, Windows, and WebAssembly with a WebGPU-capable browser.
- Use the debug inspector to edit the player fuse inventory and browse grouped entities.
