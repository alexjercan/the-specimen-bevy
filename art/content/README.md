# Itch.io page assets

`itch.html` is a paste-ready description draft, not a live itch.io page. Upload the selected PNGs and GIFs on itch.io, copy each full-size `https://img.itch.zone/` URL, and replace these placeholders in HTML/source mode:

| Placeholder | Local file |
| --- | --- |
| `REPLACE_WITH_ASSEMBLY_STALKER_IMAGE_PATH` | `screenshots/assembly-stalker.png` |
| `REPLACE_WITH_FUSE_TABLE_IMAGE_PATH` | `screenshots/fuse-table.png` |
| `REPLACE_WITH_HIDE_PROMPT_IMAGE_PATH` | `screenshots/hide-prompt.png` |
| `REPLACE_WITH_EXIT_LOCKED_IMAGE_PATH` | `screenshots/exit-locked.png` |
| `REPLACE_WITH_LOCKER_WATCH_GIF_PATH` | `gifs/locker-watch.gif` |
| `REPLACE_WITH_BOILER_RESTORE_GIF_PATH` | `gifs/boiler-restore.gif` |
| `REPLACE_WITH_FUSE_INSTALL_GIF_PATH` | `gifs/fuse-install.gif` |

`screenshots/lab-blackout.png` is an extra gallery candidate. Upload `cover.png` (630x500) as the itch.io cover image and `banner.png` (960x240) as the page banner; these are separate page settings, not images for the description. `trailer.mp4` is a separate video asset; do not paste a local path into the HTML description. Check the trailer's audio sample provenance before publishing it.
