Achievements

Seven achievement concepts for a facility escape. The icons and tiles below are art drafts for review, not live Steam achievements. The game tracks and saves these achievements locally. Steam sync is an optional build feature; no Steam app or published achievements exist yet. See docs/achievements.md.

Unlock rules

  • Track run eligibility from the start of a fresh game. Reset it on replay. Check escape conditions only when the player actually escapes.
  • Record flashbang and detector pickups, not current inventory. Using or dropping an item must not restore a no-pickup condition.
  • Buy some time now uses a local confirmed-hit signal when the monster is within the flashbang burst area and in clear line of sight. A throw, sound, or temporary protection for the player alone does not count.
  • Record completed boiler repairs. For So close, record the exit door actually opening after unlock and require the player to be caught before the escape event.
  • Count detection when the monster first enters pursuit of the player through sight or sound. Escaping pursuit later does not restore Unseen eligibility.
  • Keep gameplay rules independent of the Steamworks adapter. The Steamworks API names must match the IDs above; publish nothing until playtest verification on Steam.
